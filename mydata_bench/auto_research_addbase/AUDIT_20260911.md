## 有效性边界与是否重跑

- 未发现需要推翻已有 Robometer/SOLE 全矩阵的实现错误，因而没有盲目重跑 197,292 条预测。真实复核只写入新目录。
- “完成”指全部要求样本有尝试记录，不能解释成全部输出有效。SOLE video→text baseline 有 10 条格式失败，text→video 有 25 条；实际原文包括 `<70%</answer>`、`<22.1 seconds>25%</answer>` 等不符合契约的输出，多数没有达到 token 上限。它们是真实生成失败，单纯加大 token 上限不能修复；本轮保留失败，禁止读取解释文字猜标签后冒称原协议结果。
- 一部分 wrong-region 不存在同时间域、等大小且不相交的区域；这是控制构造不可行，不是 target 实验失败。不得将这些控制强行补齐或把对照缺失删掉后声称配对成立。
- SOLE official 同时改变原生分辨率、拼图与递推上下文，不能把优势归因于图文顺序；使用 greedy 是确定性协议对照，未复现官方随机采样分布。
- 既有 MAE 主表是五档奖励的样本平均绝对误差。RoboReward 论文的 benchmark Overall 则是固定子集的等权平均；当前自建数据没有那些原 benchmark 子集。新研究应同时报告 micro MAE 与本数据的 task-macro MAE，避免直接声称与论文 Overall 数值同口径。
- progress 与 success head 必须各自与自身 baseline 比较。success head 是 checkpoint 已训练的成功概率，不是把连续 progress 用标签调参后映射到 1/5；若它成为有效候选，最终须明确写明该 head，并同时展示 progress 的结果。
- 本轮开始读取计划前执行过一次只读 `git status --short`；没有执行任何更改本地 Git 状态的操作。读完计划后不再执行本地 Git 命令。文件名检索曾返回邻接目录的路径，没有打开其它 Robo-Dopamine 仓库内容。
