首轮理论假设：原 +/-6 将目标与背景相对赔率乘以 exp(12)，还改变视觉总注意力。引入归一化域内重分配：对选定视觉域 D 内目标 T 加 λ，随后从 D 全部 logits 减去 log[(exp(λ)Z_T+Z_(D\T))/Z_D]。固定当前 Q/K 时，D 总注意力及所有域外 key 权重保持不变，原 causal/padding mask 保持不变。该层的不变量不等价于整网输出保持不变。

主线 1：重查权重载入、官方协议、bbox/tubelet、query、独立条件失败、指标分母和相同视频配对；只针对确认的问题在新目录重跑。主线 2：直接获取 arXiv 一手来源，核对标题与机制。主线 3：先数学与真实前向验证，再探索、扩展五输入、全 cohort/视频组统计，未达标则继续提出机制改进。

## 第二候选：背景保留的质量混合（验证集结果之前记录）

第一轮 Qwen 的 image→text 在已完成剂量下没有达到探索门槛，而 Robometer success head 与 RoboReward 交错输入已有候选。为检验视觉关系信息被过度集中破坏，定义 p'_D=(1−η)p_D+η·mass(D)·p_T/mass(T)。每个背景 key 精确保留原权重的 1−η，域外权重与域总量保持不变；目标不可见时无干预。η 预定 .25/.5/.75，k 8/32/64，两个时域。该动态等效 logit 剂量由当前注意力决定，不访问标签、reward 预测、任务编号或配对关系。先在相同 discovery 上运行，所有试验记录，不基于 validation 调剂量。

## 后续 ranking 假设：观测奖励决策位置

RoboReward/Qwen 的 last_prompt 位置通常首先预测 `ANSWER` 格式文字；真正的 1–5 决策发生在格式前缀之后。新增可选 `ranking_prefix="ANSWER: "`，仅在无干预 ranking 前向附加格式前缀、观测其最后 token 的注意力，生成评分时输入完全不变。它不包含任何奖励数值，也不使用生成答案或标签。新排名存于独立 variant 目录，不能复用 last_prompt 排名后冒称决策位置。预定在 discovery 上比较 k 8/32/64；这是 head 选择变化，须与相同干预形式、强度的 last_prompt 排名比较。

## 后续 ASCD 风格证据对比（实现准备，尚未据此宣称有效）

相同输入、相同 head 上构造正向 steering 分支与目标抑制分支，按 z=(1+α)z_positive−α z_negative 合成原生类别 logits。预定 α=1、负分支域内 logit 强度 −4；正分支先用 λ=2/4/8。每条样本独立计算，无标签、配对对手、任务编号或端点阈值。

RoboReward/Qwen 在 `ANSWER: ` 格式前缀后读取全部五个奖励 token 的 logits，再在全部五类中取最大值；必须另跑相同 likelihood readout 的无干预 baseline，不能将格式规范化收益当作 attention 收益。该输出记录为 likelihood readout，raw_output=null，不伪装为自由生成文本。Robometer 保留全部十个已训练 progress bins 的 softmax 期望和原生 success logit；不允许把概率按 .5 或其它阈值直接压成 1/5。SOLE 的 CoT 百分比未定义这种直接读出，暂不套用。

正负分支、合成概率与精确 prompt 全部保存，以便检查中间类别仍然可选、输出没有端点 hard coding。此为独立 variant，需区分“rank query 改变”“原生 likelihood 读出”“attention 对比”三个因素；最终若使用此路线，须补齐因子消融。

## 后续 query 范围消融：保留预训练视觉表征

现有 all-query 方法会在中间层连续修改图像 token 自身的表示。即使层内视觉注意力质量不变，目标和背景的关系编码仍可能被改变。新增显式 `research_query_scope=readout/text`：readout 只改最终进度/最后 prompt 位置及其后的生成 query；text 只排除视觉 query。前者在固定原始输入前向中，使读出位置之前的所有 query 完全沿用原 SDPA 输出，避免直接改写视觉 token 的表征；仍可能通过后续生成的文本产生间接传播。

这是对原 all-query 方法的有意消融，不是回退或掩盖原 hook 未生效。主线 1 的原 all-query 实现已独立核验；新 variant 的诊断必须明确写 `all_query_rows=false` 与实际范围，不能混入原方法结果。预定先用质量重分配 λ=2/4/8、k=8/32/64 在 discovery 上评估，再决定是否组合证据对比。

## 同一 readout 范围的模态质量消融

质量不变方法可能保留了 baseline 本来过低的视觉注意力。新增 `positive_bias` 仅向目标 key 加 λ，不对背景另加负 bias，其闭式形式是 p'_T=exp(λ)p_T/[1+(exp(λ)−1)mass(T)]，所有非目标 key 同除该分母。它保持任意两枚非目标 key 的相对权重，包括背景与文字之间的比例，但允许总视觉质量上升；与原 ±λ 的背景/文字比例变化不同。结合 readout-only 时，读出前的视觉表征不被直接改写。诊断明确记录 domain_mass_preserved=false。预定在与 readout mass_transport 相同的模型、输入、k、λ 上比较，无新输出阈值或端点变换。

## 固定输入下的指令绑定诊断与下一假设

实际扫描发现：543 个配对中，标准独立图像与官方高分辨率均有 183 对完全相同的全帧掩码；最后一帧均为 185 对。颜色和从左数第几个物体等指令不同，干预区域却相同。因此这些数据上的任务区分不能仅由区域位置编码承担。分辨率提高使目标典型 key 数增加，却没有解除这些掩码相同的情况。原输入仍作为已接受的固定数据，推断需要额外利用指令及时间关系。

新增 `binding_transport`：先做视觉域内质量重分配，再在互不相交的原 prompt 文字域内，把固定 50% 的质量按当前注意力分给完整任务指令，其余 50% 保留原文字分布。视觉总量、原 prompt 文字总量及域外生成上下文均保持不变，两个域内操作可交换；不添加新 prompt、标签或任务 ID。任务 token 通过实际 input_ids 解码及 fast-tokenizer offsets 精确定位，要求 round-trip IDs 完全一致、任务文本恰出现一次、目标属于有效非视觉 token，否则显式报错。

预定 λ=2/4/8、k=8/32/64、任务混合份额 .5，并保留 λ=0 的 text-only 消融和任务份额 0 的 visual-only 消融。先测试原 all-query，以保持与原研究约定一致；如果另用 readout 范围，须独立标记。该候选以 PASTA 的文字强调机制与视觉重分配结合，检验空间证据和指令条件是否需要同时加强。

## 下一候选：分开选择视觉定位与指令读取 head

当前 raw-mass 排名集中于中间层的视觉定位 head，但 `binding_transport` 同时在这些 head 内强调指令。这隐含了“看目标的 head 也负责读任务”的假设，尚无证据保证。PASTA 与 Localization Heads 分别筛选文字功能和视觉定位 head，因此预定检验双列表选择：在同一无干预 ranking 前向和同一读出 query 上，分别统计 ROI raw mass 与完整 task raw mass，两个有序列表交替取尚未入选的 head，形成一个不重复的总排名。top-k 的总 head 数仍为 k，不增加到 2k。

这是对已有绑定方法的 head 选择消融。两域重分配公式、原 prompt、数据、五档输出和 k 均不变；不使用 label、reward logits 或样本配对进行排序。先固定视觉 λ=4、task fraction=.5、k=8/32/64、all/last 两范围，在 discovery 上比较。新目录 `binding_dual` 单独保存视觉、指令两种分数和选择来源；原 raw-mass 排名保留在子目录，不覆盖。初始筛选结束后再按预先冻结的候选进行完整验证。

### 绑定方案的格式观察

Qwen image→text 的部分 all-frame/top64 绑定输出为单独字符 `2`，缺少既定 `ANSWER:` 前缀，因原解析契约被记为 parse_error。已检查原文，它们不是任务 token 对齐异常，也没有被填成 reward 1。此类点不通过完整覆盖率门槛；若后续需要研究无格式干扰的绑定效应，应使用独立 variant 的相同五类 likelihood 读出及其匹配 baseline，不在原结果中偷偷放宽解析规则。

## 下一研究阶段：PASTA 式功能 profiling（少样本监督，非零样本）

目前 raw ROI mass 和文字 mass 都只是 head 功能的代理，联合绑定在部分输入上仍没有改善两类准确率。PASTA 原方法通过开发集上的实际任务表现选择 head。因此下一阶段明确采用少样本有监督的 head 选择：模型权重保持冻结，仅使用已经冻结的 discovery 70 条作为 profiling 数据。**这不是零样本方法，也不能宣称 head 选择完全无监督。** validation、old_holdout 和 full_cohort 的标签不参与 head 选择；推理进程始终不加载标签文件。

预定做法：每层 8–35 内，用视觉/指令双列表交替选出 8 个不同 head；分别只干预该层的这 8 个 head，绑定公式固定视觉 λ4、文字份额 .5，覆盖 all/last 两时域。Qwen/RoboReward 使用相同五类 likelihood baseline 与干预读出；Robometer 固定以其原生 success head 为 profiling 目标，progress 仍完整报告。所有候选类别保留，既不二值化输出，也不改 logits 的类别偏置或决策阈值。

GPU profiling 先保存每条样本的原生概率；独立 CPU 选择进程才读取 discovery 标签，计算 suc 和 fail 各自的平均负对数似然相对 baseline 的变化。每层按两类变化的较大者从小到大排列，平局再比较两类均值和层编号，使选择显式惩罚牺牲任一类。最终依层组拼接成 224 个候选 head 的固定排名；top-k 总预算预定 8/16/32/64（分别 1/2/4/8 个层组）。组内顺序来自无标签双列表，不声称做了逐 head 的监督归因。

选择文件在完整验证前冻结，并保存训练 ID 清单、概率文件哈希、每层两类损失变化及排名。之后新的推理只读取固定 head 索引，不读取标签、任务 ID 或同视频配对关系。该方案与既有无监督方法分开汇报，若有效还需相邻 k、wrong-region、低排名层组和原 ±6 对照。此时仍不预设结果一定改善。

## 第十一轮候选：保留关系上下文的空间软核（实现前，14:58）

二值ROI的标准输入末帧中位仅2个视觉key；其内部可能不足以表示盘子、邻近对象与空间关系。基于已核验文献对定位与判别分工、背景保留的分析，提出在正分支保留ROI core权重1，同时给同一时域span的邻近key连续的空间权重 g_j=exp(−d_j²/(2σ²))。d是在各span的合并patch网格上，到最近ROI key中心的距离，横纵坐标分别除以grid宽高；预定σ=.15（图像宽/高的比例）。原visual域内以exp(λg_j)倾斜并归一化，保持该域总质量与域外所有key权重；不修改已接受bbox/cohort，不重新标注。
