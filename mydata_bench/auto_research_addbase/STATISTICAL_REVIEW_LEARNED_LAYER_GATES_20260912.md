## 11项统计谬误核查

| 项目 | 本轮核查结果 |
| --- | --- |
| Simpson反转 | 60条件按相同task样本数重构总体MAE，逐值在浮点容差内一致；没有“所有任务同方向而总体反向”。45/60条件同时有改善和恶化任务，总体不能代表每个任务。来源`audit/learned_layer_gates_statistical_structure_20260912_140250.json`。 |
| 生态谬误 | 评分使用逐例预测，CI单位为视频组；不从模型整体均值推断每条指令均改善。 |
| Berkson选择偏差 | discovery按既定视频哈希和任务覆盖选择，只有28视频组；不能外推到任意真实机器人任务分布。 |
| Collider偏差 | 先要求完整推理、按冻结规则做效能选择，未以“预测正确”作为逐例纳入条件；候选点筛选本身仍会产生选择偏差。 |

| 幸存者偏差 | 4200干预/700baseline均完整有效，保留全部60条件和失败输入，未丢弃坏点。 |
| 多重寻找效应 | 本检查点每指标提供Holm校正，但范围仅当前checkpoint（且含重复阈值）；不覆盖此前31轮探索，更不能消除训练再代入偏差。不声称全研究家族错误率受控。 |
| 分析路径自由度 | 本轮参数、最终固定步和选择规则先登记；第31轮本身是在前轮失败后提出，所以全研究仍属自适应探索。 |
