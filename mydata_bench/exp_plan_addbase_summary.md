# Robometer-4B 与 SOLE-R1-8B 实验总结

## 1. 实验范围与口径

本轮对应 [exp_plan_addbase.md](../exp_plan_addbase.md)，新增 Robometer-4B 与 SOLE-R1-8B，
比较五种普通输入和各自官方输入。每种输入均完成最后一帧/全帧、top-k=8/32/64 的
attention steering，并设置 wrong-region 和 low-rank-head 控制，共 **12 个配置、228 个条件**。

Baseline 使用完整数据集 **1213 条（407 suc / 806 fail，34 task）**；steering 使用
**846 条 grounding cohort（268 suc / 578 fail，28 task）**，变化均与同 cohort baseline 比较。
MAE 按五档奖励计算（分档阈值 .125/.375/.625/.875，标签 suc=5、fail=1）。下表准确率采用
严格端点阈值：suc 进度≥.875、fail≤.125 才算正确；无效输出不计正确，分母固定，MAE 则取有效输出均值。
宽阈值 .2/.8 的关键差异另行说明。原主表使用 progress 输出，Robometer success head 单列报告。

### Robometer success head：更贴近当前成功/失败判断

**success head 的预测目标更贴合当前 suc/fail 标签。** 两个 head 读取相同的末帧 prog_token
表征；progress head 输出任务进度，success head 通过二分类训练输出成功概率，区别在训练目标和
读出方式。本节沿用五档 MAE 和两套端点阈值，所有 baseline 均为完整 1213 条。

官方输入下，success head 相比 progress head 的 MAE 从 **2.0058 降至 1.5664**，严格总准确率
从 **32.07% 升至 47.57%**；fail 从 0.25% 升至 29.40%，suc 则从 95.09% 降至 83.54%。

平衡准确率为 64.02% → 69.44%。该二分类口径与表中的严格端点准确率不同，阈值未在本数据上调优。
video → text 的 success 输出仍几乎全判失败，说明使用 success head 本身不能消除协议退化。

逐任务看，官方输入的 success MAE 在 **20/34 个 task 降低、11 个持平、3 个升高**。
task3_1、task4_1、task4_7 退化，收益并非覆盖所有任务。

## 3. Attention steering 结果

下表保留 progress 输出的三个 **样本完整（n=846）的代表点**：Robometer 全部 target 中的最低 MAE 点，
以及两模型各自官方输入的最低 MAE 点。这些是观察结果后选出的探索性配置；全部 k 见详细报告。

| 模型与输入 / 干预范围 | k | MAE | 总准确率 | suc 准确率 | fail 准确率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Robometer，text → images / 全帧 | 8 | 1.8889 → 0.9823 | 28.61% → 38.06% | 83.58% → 67.16% | 3.11% → 24.57% |
| Robometer，官方输入 / 全帧 | 32 | 1.8132 → 1.1147 | 30.85% → 24.59% | 96.64% → 63.81% | 0.35% → 6.40% |
| SOLE，官方输入 / 最后一帧 | 32 | 1.3121 → 1.2199 | 44.44% → 52.13% | 30.60% → 33.21% | 50.87% → 60.90% |

### Progress 输出的主要发现

1. **Robometer 的 MAE 收益较一致，但没有双类同时改善。** cohort 中 36/36 个 target 降低
   MAE，34 个通过 Holm 校正；两套阈值下均没有一个条件同时严格提高 suc 与 fail 准确率。
   text → images / 全帧 / k8 在 27/28 个 task 上降低 MAE，宽阈值准确率从
   34.28% / 92.54% / 7.27% 变为 70.09% / 71.64% / 69.38%，仍有 suc 损失。
2. **SOLE 的改善尚未得到统计确认。** 36 个 target 比较中只有 22 个样本完整，MAE 下降与
   上升各 11 个，没有改善通过 Holm 校正。官方最后一帧 k32 的严格准确率双类均升，
   但 ΔMAE 的 95% CI 为 [−0.2019, 0.0164]，Holm p=1；宽阈值下 suc 反而从 35.07%
   降至 34.33%，所以也不能称为跨阈值的稳定收益。
3. **全帧和更大的 k 都不保证更好。** SOLE 官方全帧 k8/32/64 的 MAE 为
   1.3369/1.3972/1.3298，全部高于 baseline 1.3121；交错输入最后一帧 k64 还出现
   MAE 恶化 +0.1501（cohort Holm p=0.0190）。

### Progress 输出的 Pairwise 与控制组证据

- **Robometer text → images / 全帧 / k8：** 543 对同视频 suc−fail 的平均连续差从
  0.2540 增至 0.5071，负差率从 20.07% 降至 13.81%，支持指令区分度改善。
- **Robometer 官方全帧 k32：** 在共同 846 条上，target MAE=1.1147，优于 wrong-region
  的 1.3558 和 low-rank 的 1.7766。但 578 条 fail 中有 479 条落在奖励 2，严格 fail
  准确率仅 6.40%；离散 suc−fail 负差对数还从 10 增至 29。误差下降与端点、排序改善并不等价。
- **SOLE 官方最后一帧 k32：** target MAE=1.2199，低于两控制的 1.3215、1.2813；
  543 对连续负差率从 37.75% 降至 30.20%。这提供描述性的选择性证据，仍需独立验证。

Robometer 全部 36 个 target 在各自四条件共同有效样本上均优于两控制，SOLE 只有 12/36。
这些控制与配对结果为描述性比较，不另作显著性声明。

- **text → images / 全帧 / k8** 的 success MAE 为 0.5378，严格总准确率达到 83.22%；
  这也支持保留原 progress head 候选配置，并同时观察两个 head。
- success head 的 36 个 target 中 **32 个降低 MAE、4 个升高**；严格阈值下仅
  text → video / 全帧 / k8 同时提高 suc/fail，宽阈值下有 2 个配置双类提高。
  success head 的这些结果未另做显著性检验，不能沿用 progress head 的 Holm 结论。

官方最后一帧 k32 在 **24/28 个 cohort task 上降低 success MAE**，task2_2、task2_3、
task3_6、task3_7 退化；排除 ranking 视频组后的 730 条 holdout MAE 为 0.5822，严格
总/suc/fail 准确率为 79.32% / 67.95% / 84.68%，仍有同域与类别权衡的限制。

## 5. 有效性边界

- 全矩阵已完成，共 197,292 次终点尝试：196,797 次有效、315 次格式失败、180 次控制区域
  不可构造。SOLE 的 14 个不完整 target 比较保留为描述性结果，不能混入完整样本排序。
- 排除全部 36 个 ranking 视频组后得到 730 条 holdout。Robometer 仍有 35/36 个 target
  降低 progress MAE、34 个通过校正；SOLE 仍无改善通过校正。该 holdout 与 cohort 重叠且同域，
  不属于独立复现。cohort 中 fail 占 68.32%，只看总准确率容易掩盖 suc 损失。
- Progress MAE 检验按视频组处理相关性，cohort/holdout 各对 72 个 target 比较做 Holm 校正，
  不完整比较以 p=1 保留。最佳配置仍是事后选择，结论不外推到新任务或机器人闭环成功率。
- SOLE 官方输入采用七步自身绝对进度递推，进度不累加；本轮 greedy/512-token 解码
  与官方随机解码不同，因此属于官方输入构造的评测，并非完整复现官方推理设置。

## 6. 结论

面向当前成功/失败判断，建议将 **success head 纳入后续主要评估**；本轮保留原 progress 主指标，并将 success 结果并列报告。最值得在独立数据上复现的是：

1. **Robometer success head：官方输入、最后一帧 steering、top-32。** success MAE 最低，
   成功/失败判断更贴合本任务，但 suc 损失和部分 task 退化仍需解决。
2. **Robometer 双 head：text → images、全帧 steering、top-8。** progress MAE 最低，
   success head 的严格总准确率达到 83.22%，适合作为另一候选配置。
3. **SOLE-R1-8B：官方输入、最后一帧 steering、top-32。** 当前证据尚不足以确认稳定收益。

本轮支持 attention steering 改变模型输出并在部分配置上改善离线指标，尚未得到跨模型、
跨协议稳定提升 suc/fail 判断的方案。后续应固定候选配置，在独立视频组上复现，再分别调整
bias 与 k，并以双类准确率和配对排序共同验收。
